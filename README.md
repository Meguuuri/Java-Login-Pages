# MP3_CalipesCortezDizon - NetBeans 12.4 Ant Web Application (Java EE 5 / GlassFish 2.x)

1. Open NetBeans -> File > Open Project -> select this `MP3_CalipesCortezDizon` folder.
   NetBeans generates `nbproject/build-impl.xml` and `genfiles.properties` on first open (this is normal).
2. If prompted with "Resolve Server Problem", register your GlassFish 2 install
   (Services > Servers > Add Server) and pick it under Project Properties > Run.
3. Source/target level is 1.6 - no Java 7/8 syntax (no diamond, lambdas, try-with-resources, String switch).
4. Run: http://localhost:8080/MP3_CalipesCortezDizon/  (login: admin / password123)
